この利用規約（以下「本規約」）は、「氷途」（以下「本サービス」）の利用条件を定めるものです。ユーザーは、本規約に同意したうえで本サービスを利用するものとします。

第1条（定義）
1. 「運営者」とは、本サービスを開発・運営する個人をいいます。
2. 「ユーザー」とは、アカウント名とパスワードを登録して本サービスを利用する人をいいます。
3. 「ユーザーID」とは、アカウントごとに発行され、ユーザーに表示される識別番号をいいます。
4. 「データ」とは、アカウント名、パスワード、ユーザーID、ランクや所持キャラなどのゲーム内情報をいいます。
第2条（アカウント）
1. アカウント名・パスワード・ユーザーIDは、ユーザー自身が責任をもって管理してください。
2. アカウント名・パスワード・ユーザーIDが第三者に知られたことによる損害について、運営者は責任を負いません。
第3条（料金・ゲーム内要素）
1. 本サービスは無料です。課金要素はありません。
2. ガチャ、ログインボーナス、スタミナなどの内容や確率は、予告なく変更することがあります。
3. ゲーム内のキャラ・アイテム等に金銭的な価値はなく、換金や売買はできません。
第4条（データの取扱い）
1. 運営者が保存するのは、アカウント名、パスワード、ユーザーID、ゲーム内情報のみです。メールアドレスや本名などは収集しません。
2. パスワードはソルト付きでハッシュ化して保存し、運営者も元のパスワードを見ることはできません。
3. データは本サービスの提供のためだけに使い、第三者に提供しません。
4. データの所有権は原則としてユーザーにあります。
5. 退会・データ削除を希望する場合は、ユーザーIDを添えて運営者に連絡してください。確認のうえ削除します。
6. 本サービスの終了後も、データは自動では削除されません。削除を希望する場合は前項により連絡してください。
第5条（禁止事項）
次の行為を禁止します。違反した場合、運営者はアカウントの利用停止や削除を行うことがあります。
• 不正アクセス、サーバーへの過度な負荷、バグや不具合の悪用
• 他人のアカウントの利用
• その他、運営者が不適切と判断する行為
第6条（サービスの変更・終了）
本サービスは個人運営のため、運営者の都合により、予告なく内容の変更、一時停止、終了を行うことがあります。
第7条（免責・規約の変更）
1. 運営者は、データの消失や不具合などにより生じた損害について、責任を負いません。
2. 運営者は、必要に応じて本規約を変更できます。変更後に本サービスを利用した場合、変更に同意したものとみなします。
